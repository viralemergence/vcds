doi

array string nullable required

A centrally registered identifier symbol used to uniquely identify objects given by International DOI Foundation. The DOI system is commonly used for electronic documents such as journal articles.

Examples: 10.1603/ME10007
Constraints: minItems: 1; pattern: ^10[.][0-9]{4,9}[/][^\s]+$
URI: https:/w3id.org/vcds/v1.2.0/terms/doi
Term Reference: http://purl.obolibrary.org/obo/OBI_0002110

experiment_id

array string required

This grouping identifier connects different sample types that originate from the same experimental conditions and virus-vector combination within a study. The identifier is composed of a prefix, pmid, and a seven digit identifier.

Examples: cmt_12345678_0000001, aed_87654321_0000001, tck_1_0001111
Constraints: minItems: 1; pattern: ^[a-z]{3}_[0-9]{1,9}_[0-9]{7}
URI: https:/w3id.org/vcds/v1.2.0/terms/experiment_id
Term Reference: http://purl.org/dc/elements/1.1/identifier
Defined in: https:/viralemergence.github.io/vcds/v1.2.0/vcds_schema.json
